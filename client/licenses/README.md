# Local licence texts

Canonical licence texts for licences that no installed package ships a copy of,
picked up by `scripts/gen-licenses.mjs` and folded into `src/licenses.ts`.

- `OFL-1.1.txt` — SIL Open Font License 1.1 (26 February 2007), from
  <https://openfontlicense.org/documents/OFL.txt>. Needed because the vendored
  Keyrune and Mana font binaries carry no licence metadata of their own: both
  are IcoMoon builds whose name table holds only the designer.

Files here are verbatim upstream texts. Do not edit them.
